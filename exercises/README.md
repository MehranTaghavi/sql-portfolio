# SQL Exercises

This folder contains all my SQL practice exercises organized by topic.

## Structure
- **01-basics/** - SELECT, WHERE, LIKE, BETWEEN
- **02-group-by-having/** - GROUP BY, HAVING, Aggregate Functions
- **03-subquery/** - Simple and Correlated Subqueries
- **04-cte/** - Common Table Expressions
- **05-joins/** - INNER, LEFT, RIGHT, FULL JOINs
- **06-window-functions/** - ROW_NUMBER, RANK, LAG, LEAD

Each topic includes practical examples and solutions.
